# Brand

## Name

**provio.**

*Prove* + *io*: every action an AI agent takes at its inputs and outputs,
checked before it runs and provable afterwards. The name was chosen in
September 2026, replacing *writ*, which collided with other projects in the
same category; it is short, has no dictionary meaning to compete with, and
is the same on GitHub, PyPI, npm and crates.io.

## Logo

The mark is the name as the brand writes it — **provio.** — drawn as a
single-weight geometric wordmark. The period is the seal: the one accent
colour, meaning *authorized and recorded*. The icon is the `p` and the seal
on a dark rounded square. `scripts/gen_brand.py` draws the SVGs and
`scripts/render_brand_png.ps1` renders the PNGs.

| Asset | Use |
|---|---|
| [`assets/brand/hero.svg`](assets/brand/hero.svg) | README and page headers |
| [`assets/brand/wordmark-light.svg`](assets/brand/wordmark-light.svg) | wordmark on dark backgrounds |
| [`assets/brand/wordmark-dark.svg`](assets/brand/wordmark-dark.svg) | wordmark on light backgrounds |
| [`assets/brand/icon.svg`](assets/brand/icon.svg), `icon-512.png`, `icon-180.png`, `icon-32.png` | app icon, org avatar, favicons |
| [`assets/brand/social-preview.png`](assets/brand/social-preview.png) | 1280×640 link preview (GitHub, Open Graph) |

Letters are paths, not text, so the mark renders identically everywhere. Keep
clear space of one stroke width around it, never recolour the letters with
the accent, and never move the accent off the period.

| Token | Hex | Role |
|---|---|---|
| ink | `#0b0f14` | background |
| text | `#dbe4ec` | letters on dark |
| accent | `#4ec9a5` | the seal; links and highlights |
| allow / deny / ask / redact | `#3fb950` / `#f85149` / `#d29922` / `#a371f7` | verdict colours only |
